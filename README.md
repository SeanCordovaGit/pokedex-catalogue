# PokeDex Catalogue

A React + Vite Pokédex catalogue that uses PokéAPI data with a custom Pokémon Legends-inspired interface, intro screen, animated home scene, searchable catalogue cards, type filtering, and detailed Pokémon modal pages.

## How To Run

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```


## How It Works

The app loads Pokémon data from PokéAPI:

- `GET /pokemon?limit=1010&offset=0` loads the catalogue list.
- Individual Pokémon details are fetched as cards become visible.
- Species data is fetched when a Pokémon detail modal opens.
- Type data is fetched for filters and weakness display.

The first screen is an animated intro. Pressing Enter or clicking the intro fades it out and triggers the home-screen logo reveal.

The home screen starts in Day mode by default. When a user switches between Day and Night, the choice is saved in `localStorage` and restored on later visits.

## Main Files

- `src/App.tsx` - React components, data fetching, filtering, modal logic, and animations.
- `src/index.css` - global styling, layout, responsive behavior, and visual effects.
- `public/assets/` - images, GIFs, audio, and other static assets served by Vite.
- `dist/` - production build output generated by `npm run build`.

## Features

- Animated title screen with music toggle.
- Day/Night home mode with saved preference.
- Search by Pokémon name or ID.
- Sort by ID or name.
- Filter by type.
- Load-more catalogue grid.
- Pokémon detail modal with artwork, types, stats, abilities, weaknesses, and nearby Pokémon rail.
- 8-bit side-rail sprites.
