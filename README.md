# Pokedex Catalogue

A simple Pokedex web application built with React and TypeScript using the PokeAPI.
Users can browse, search, filter, and view detailed information about Pokémon in a clean, responsive interface.

---

## 🚀 Features

* Card-based Pokémon catalogue
* Search by Name or ID
* Sort by ID or Name
* Filter by Type and Region
* Favorites system
* Infinite scroll + Load More functionality
* Detailed Pokémon modal view
* Weakness calculation based on type matchups
* Responsive UI design

---

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* PokeAPI

---

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/SeanCordovaGit/pokedex-catalogue.git
cd pokedex-catalogue
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

---

## 📌 Notes

* Pokémon data is fetched dynamically from the PokeAPI.
* Caching is implemented to reduce redundant API calls.
* Type data is used to compute Pokémon weaknesses.
